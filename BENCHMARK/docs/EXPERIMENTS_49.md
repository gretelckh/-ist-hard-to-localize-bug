## 2. Diagnosis LLM baseline — DONE

- Code: `metrics/predict_llm_49.py`
- What: for each bug, feed the LLM only the surface_text; ask it to predict the ORIGIN layer
  (Host/Client/Server/Transport); compare to `origin`.
- Credentials: `.env` (CITYU_BASE_URL / CITYU_API_KEY / CITYU_MODEL), CityU DeepSeek proxy,
  temperature=0, single-token answer. Reads `diag_dataset_49.json`.
- Output: `data/full_pool/llm_answers_49.json` (49 records: issue, origin, channel,
  surface_text, pred, ok). Run: `python metrics/predict_llm_49.py`.
- RESULT (baseline, no metadata): overall **77.6%** (38/49); **non-Server (13) 15.4%** (2/13);
  per-layer Server 36/36, Transport 2/5, Host 0/4, Client 0/4.
- Insight: non-Server bugs are reported at Server and the LLM is misled to Server
  (Host/Client 0%). Report the 13 non-Server (15.4%) as the honest hard-case number.

## 4. Diagnostic-clue intervention (Phase B) — DONE (2026-10-11)

- Migrated the clue tool to the 49 bugs: `analysis/make_diag_clues_49.py` -> `data/full_pool/diag_clues_49.json`
  (per-bug channel + directional hint, never names the origin layer). Channels mapped: pushed-server /
  silent / caller-exception / single-layer-(masked|correct) / registration-error (new hint). No hint
  asserts an origin layer (sanity asserts=0).
- Ran `python metrics/predict_llm_49.py --clues` -> `data/full_pool/llm_answers_49_clues.json`;
  `--clues-leaky` -> `llm_answers_49_leaky.json`.
- Compare `analysis/compare_clues_49.py` -> `docs/CLUES_49_RESULTS.md` + `data/full_pool/clues_49_summary.json`:
  | Condition | Overall (49) | Non-Server (13) |
  |---|---|---|
  | Baseline (no clue) | 77.6% | 15.4% |
  | +Honest directional clue | 79.6% | **23.1%** (+7.7pp) |
  | +Leaky channel label (control) | 73.5% | **0.0%** |
- Insight: honest clue helps the hard non-Server cases (+7.7pp); the leaky negative control does NOT
  help (0% on non-Server) -> gain comes from guidance content, not a leaked layer label. Rules out
  circular-intervention critique (matches old synthetic direction 45%->52.5%, control 41.2%).
